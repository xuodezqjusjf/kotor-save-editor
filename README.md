## Overview

KOTOR Save Editor lets you view and modify every field in KotOR 1 and 2 save files: character stats, inventory, global variables, journal flags, and party member states for troubleshooting and custom starts.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **KOTOR Save Editor** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Character Editor** | Modify all character attributes, feats, and force powers |
| **Inventory Control** | Add, remove, or edit any item in the character's inventory |
| **Global Variables** | Inspect and flip story-progress flags to fix broken quests |
| **Party Management** | Edit companion join-state, equipment, and influence levels |
